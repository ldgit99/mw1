# Block Survivor Mission

- 마인크래프트 감성의 2D 웹 액션 게임입니다.  
- 귀여운 플레이어 캐릭터를 조작해 다양한 유령(좀비)을 처치하고 스테이지 미션을 클리어합니다.
- 초등학생 2학년이 바이브 코딩으로 만든 게임입니다. 

## 주요 기능
- 10개 스테이지 미션
- 스테이지별 목표 처치 수 증가 (`50 ~ 500`)
- 스테이지마다 대왕 유령 등장
- 대왕 유령 처치 시 `SKILL +10` (처치 수 +10 반영)
- 다양한 유령 타입 등장 (예: 귀신, 강시, 드라큘라 등)
- 유령 타입별 체력/이동속도 차등
- 플레이어 이동/사격/스킬 시스템
- 사과 아이템 획득 시 HP 회복
- 사운드 효과(발사/피격/회복/스킬)
- 다시하기, 일시정지, 스테이지 선택 UI
- 로컬 프로필 저장(최고 스테이지, 누적 처치 수, 사운드 설정)

## 조작법
- 이동: `WASD` 또는 `방향키`
- 조준: `마우스`
- 기본 사격: `마우스 좌클릭`
- 자동 조준 사격: `Space`
- 폭탄: `1`
- 미사일: `2`
- 방어막(10초): `3`

## 스킬 요약
- 폭탄
  - 스테이지당 3회 사용
  - 플레이어 주변 광역 피해
- 미사일
  - 스테이지당 2회 사용
  - 대왕 유령 자동 추적
- 방어막
  - 10초간 충돌 피해 무효
  - 캐릭터 주변에 방어막 시각 효과 표시

## 스테이지 진행 규칙
- 각 스테이지는 목표 처치 수 + 대왕 유령 처치를 모두 만족해야 클리어됩니다.
- 스테이지가 올라갈수록:
  - 플레이어 최대 HP 증가
  - 일반 유령 난이도(체력/속도/동시 등장 수) 상승
  - 대왕 유령 HP 증가
- 유령은 동시 등장 제한 내에서 생성됩니다.

## 실행 방법
이 프로젝트는 빌드 도구 없이 브라우저에서 실행됩니다.

1. 프로젝트 폴더로 이동
2. 정적 서버 실행 (아래 중 하나)
3. 브라우저에서 `http://localhost:5500` 또는 서버가 안내한 주소로 접속

### 방법 A) VS Code Live Server
- `index.html` 우클릭 -> `Open with Live Server`

### 방법 B) Python 내장 서버
```bash
python -m http.server 5500
```

### 방법 C) Node serve
```bash
npx serve .
```

## GitHub Pages 배포
1. GitHub 저장소에 코드 푸시
2. 저장소 `Settings` -> `Pages`
3. `Build and deployment`에서:
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)`
4. 저장 후 배포 URL 접속

## 주의 사항
- `Space`, `1`, `2`, `3`, 방향키는 브라우저 기본 동작(스크롤 등)을 막도록 처리되어 있습니다.
- 사운드 재생은 브라우저 정책상 사용자 상호작용(클릭/키입력) 이후 활성화됩니다.
